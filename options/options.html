ISA — Custom Fingerprint Rules

Rules you add here are merged into the built-in ruleset at scan time and marked custom in the popup. Use the same signal model as lib/technologies.json: a technology is only reported when at least one signal actually matches — leave a field blank to skip that signal type.

Extended technology pack (GPL-3.0, optional)

Adds ~29 additional technology fingerprints (PayPal, Paddle, PIXI.js, Pantheon, and others) converted from webappanalyzer, a community-maintained continuation of Wappalyzer's original fingerprint dataset. That dataset is licensed GPL-3.0 — copyleft. ISA's own code stays MIT either way, but if you enable this and then redistribute your copy of ISA with it turned on, GPL-3.0's terms (source availability, same license) apply to at least this data file. Off by default for exactly that reason — read GPL-PACK-NOTICE.md in the project root before enabling this on anything you plan to redistribute or ship.

Namespaced CSS custom properties (like --acme-primary-color) are unusually reliable — a framework author deliberately picks a prefix to avoid collisions, so a match rarely happens by accident.

CSP-allowlisted domain signal

Matches a domain listed in the page's Content-Security-Policy header. Weaker evidence than an actually-observed request — a site can allowlist a domain it doesn't currently use — so keep confidence modest here relative to your other signals.
